## 现代燃油盗窃如何运作

知己知彼，百战不殆：

### 经典模式（2-5分钟完成）

1. **踩点**：在加油站或休息区选定目标车辆
2. **分散注意力**：同伙引开司机视线或阻挡视线
3. **抽油**：使用便携式高功率抽油软管，几分钟内抽走50-200升
4. **消失**：混入车流，神不知鬼不觉

### "隐形"盗窃（更难发现）

一些腐败的加油员会**虚报加油量**，实际只加部分油量，差额被私吞。没有实时监控，这种盗窃可能持续数月才被发现。

## 解决方案1：超声波燃油液位传感器

传统流量计有个问题：**它测量的是加进去多少，而不是剩下多少**。超声波传感器改变了游戏规则。

### 工作原理

- **安装位置**：安装在油箱内（无需打孔，无泄漏风险）
- **测量方式**：发射超声波计算液面精确高度
- **精度**：±2毫米精度（标准油箱可检测5升差异）
- **上报频率**：每30秒实时更新数据

### 智能检测

真正强大的不是测量本身，而是**智能分析**：

```
场景：卡车停在休息区

14:30:00 - 液位：245.3升 ✅ 正常
14:30:30 - 液位：245.1升 ✅ 正常（发动机关闭状态消耗）
14:31:00 - 液位：198.7升 ⚠️ 警报：30秒内下降46.6升
14:31:05 - 系统：推送通知+短信给车队经理
14:31:10 - MDVR：自动激活侧方摄像头录像
```

**结果**：经理在盗贼完成作案**之前**就已收到警报。

## 解决方案2：带燃油逻辑的智能地理围栏

传统地理围栏只会提示"进入/离开"。智能地理围栏会问**为什么**。

### "授权加油站"型地理围栏

```javascript
规则："授权加油站"
- 位置：批准的PEMEX/Chevron加油站坐标
- 允许行为：燃油消耗（预期下降）
- 警报：若无消耗（可能是加油设备故障）
```

### "高风险区域"型地理围栏

```javascript
规则："无人看守休息区"
- 位置：57D、45D号公路已知高风险区域
- 预期行为：燃油**不应**下降
- 警报：液位下降>5升立即触发
- 附加动作：激活摄像头"监控模式"
```

### "异常停留"型地理围栏

```javascript
规则："异常停留"
- 条件：发动机关闭+无移动>30分钟
- 位置：非授权休息点
- 警报：通知主管，可一键呼叫司机
```

## 解决方案3：AI车载录像机（MDVR）：让盗贼无处遁形

传感器检测盗窃。摄像头**证明是谁干的**。

### 自动响应系统

当燃油传感器检测到异常下降时：

1. **第0秒**：检测到液位下降
2. **第2秒**：MDVR（D604/D904）接收激活信号
3. **第3秒**：侧方和后方摄像头开始高清录像
4. **第5秒**：可选本地警报器响起（威慑）
5. **第10秒**：实时视频流推送至监控中心
6. **第30秒**：事件片段自动上传云端（不可篡改证据）

### 摄像头捕捉到什么

- **嫌疑车辆车牌**（停在油箱旁的车辆）
- **作案人员面部**（即使戴面罩，也有体态特征）
- **作案手法**（软管类型、容器特征）
- **精确时间戳**（与传感器数据同步）

### 真实案例：从怀疑到逮捕

*克雷塔罗的一位客户每月损失约15,000升燃油。安装传感器+MDVR后，第一周就拍到一伙在工业园区作案的盗贼。车牌清晰、面部可见，州警据此逮捕3人。此后损失归零。*

## 解决方案4：司机行为分析

并非所有盗窃都来自外部。有时问题出在**内部**。

### 系统检测的可疑模式

| 可疑模式 | 指标 | 系统动作 |
|:---|:---|:---|
| 某路线燃油消耗比平均值高30% | 可能抽油或倒卖 | 向主管发送路线对比警报 |
| 频繁在非授权区域停车 | 可能"送货"给第三方 | 生成路线效率报告 |
| 偏离规划路线+燃油异常 | 可能向第三方销售 | 地理围栏+燃油联合警报 |
| 加油频率异常频繁 | 可能"重复报销"（一次真加，一次虚报） | 与加油站票据交叉验证 |

**重要**：这不是用来"监视"司机的。而是用来**保护诚实司机**，快速识别可能表明以下情况的异常：

- 强迫盗窃（司机被胁迫）
- 机械故障（真实泄漏）
- 加油错误（油箱加错）

## 常见问题

**多油箱卡车能用吗？**
可以。每个油箱安装传感器，系统汇总各箱容量。即使只抽一个油箱的部分燃油也能检测。

**盗贼剪断线路怎么办？**
FleetGoo超声波传感器带备用电池（8-12小时）。主连接被切断前会立即发送"防拆"警报。

**能接入我现有的追踪系统吗？**
可以。我们的REST API可与大多数平台集成（Geotab、Samsara、Verizon Connect或自有系统）。

**如果在无蜂窝信号区域被盗怎么办？**
MDVR本地存储高达2TB视频。恢复信号后自动上传标记事件。传感器也可本地存储7天数据。
